# Typical diagnostic errors

These images are selected from the v1 frame-level diagnostic run and are kept
only to demonstrate the error-recording workflow.  The v2 model and final
20-independent-object evaluation must generate a new set before submission.

- `cup_duplicate_detection.jpg`: an extra cup prediction in a cup scene.
- `multi_object_missed_detection.jpg`: only part of a multi-object scene was detected.
- `phone_false_positive.jpg`: a correct phone plus an additional false positive.
